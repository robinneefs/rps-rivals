# Local overhaul checkpoint — 27 October 2026

This checkpoint saves the existing browser overhaul on `codex/edits`, at unchanged version **2.2.0**. It is a local development checkpoint, not a release or deployment.

## Saved scope

- Native 192 × 240 monitor, approved cabinet/marquee/joystick and engraving, rooftop/clouds, Taiko/Riot combat presentation and synchronized choreography.
- Approved Home artwork, random Riot/Taiko/Anchor portraits and breathing, native M6X11 menu typography, entrance, Chain Shift intro, CRT treatment and One More Round music.
- Options and the remaining online/room/result menus, their padding cleanup, existing actions and settings, and draggable mouse/touch volume meters.
- Runtime assets, source artwork and prompts, font licences/attribution, preparation/install tools, retained experiment sources, and representative review captures. Experimental assets remain experiments; their inclusion does not approve or activate them.
- How to Play retains its earlier implementation and the necessary pre-existing coordinate adaptation to the 192px monitor. It was deliberately excluded from the menu redesign.

The checkpoint omits local `.claude/launch.json` and `.codex/config.toml`, bulk generated animation/review-frame directories, older runtime screenshots, and redundant study renders. These files were preserved on disk, not deleted or reset. The exact excluded list is in [2026-10-27-excluded.txt](2026-10-27-excluded.txt). Build output, dependency caches and Playwright reports are already ignored. A clone can build the saved game without these excluded files; some old review-page animations need their capture/preparation helpers to regenerate frames.

## Final review fixes

- Cancelling a pending room join now re-enables the native room-code input, so the player can edit and retry. The menu browser helper verifies the pending, cancelled, editable states on desktop and touch layouts.
- Browser smoke tests now allow real asset loading to finish before starting the simulated scene-time budget. This fixes the earlier intro timeout without changing the game's timing or skipping the intro under test.
