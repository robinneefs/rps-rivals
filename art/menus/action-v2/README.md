## Font

Latest correction after in-game CRT review: default is now the game's explicit5x7 bitmap alphabet from `apps/game/src/assets/glyphs.ts`, drawn in exact2x blocks (14px capitals), with trimmed glyph columns and tighter word spaces. No outline font rasterizer, hinting, anti-alias threshold or shear is used. Every font pixel, including gradient and shadow, occupies uniform2x2 RGBA blocks. `native/bitmap-grid-check.json` records the automated check. Label placementx14/y172,192,212 stays on even native coordinates. This avoids the uneven stroke widths baked into thresholded Pixelify glyphs (16px CPU label had241 partially covered edge pixels before thresholding). PNGs normal/selected and default atlas use this bitmap treatment. Browser offers it first, alongside previous Pixelify sizes. Source PNGs still use the same176x20 atlas cells.

`production-home.png` shows the current actual game with CRT; `production-home-crt-off.png` shows the same lettering with CRT off. `production-home-pixelify16.png` preserves the prior in-game lettering. `node tools/art/capture-main-menu.mjs --font-study` recaptures both filter modes without changing the user's settings. The filter itself is untouched. `font-size-comparison.png` now shows bitmap,14,16,18,20 left-to-right. The paragraph below documents the preceding font-size study.

Audit found Jersey10's design bounding coordinates on75-unit increments in a1400-unit em: prior24px render did not map this cleanly to integer design pixels. The artificial row-by-row italic shear also broke repeated blocks. V2 uses bundled Pixelify Sans Bold(weight700), upright with NO shearing or text resizing. Browser now compares native14/16/18/20px renders;16px is the review default, not a claim that every glyph is uniquely optimal at that size. Smaller sizes use1px shadow,18/20px use2px shadow. All variants keep binary alpha and are vertically centred in the same176x20 cells. Highlight remains yellow-to-orange in2-row colour bands. Full font and SIL OFL1.1 licence in art/fonts/pixelify-sans/. Each font-size atlas is native/labels-SIZE.png; default atlas/individual states use16px. font-size-comparison.png shows14/16/18/20 left to right, plus individual native full-screen stills. No dependency on installed system fonts.
