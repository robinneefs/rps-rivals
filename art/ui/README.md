# Combat UI hand-icon studies

Current selection: **v6 pictograms**, returned to explicitly at the user's request. The dev round-review harness reduces those smooth source images into a 24-pixel hand footprint, colours/embosses them for the move coins, and loads them only for `?roundReview`. Normal gameplay's production hand artwork has not been replaced yet.

| Study | Direction / status |
| --- | --- |
| hand-moves-v1 | First generated pixel-art hands |
| hand-moves-v2-smooth | Smooth source artwork using the fighter generation style |
| hand-moves-v3-serious | More anatomical, serious hands |
| hand-moves-v4-white | White hands with heavier line work |
| hand-moves-v5-simple-white | Simpler white hands and extra-heavy outlines |
| hand-moves-v6-pictograms | **Currently selected**: first very simple compact pictograms |
| hand-moves-v7-compact-hands | Added hand anatomy; superseded after actual-game review |
| hand-moves-v8-native | Code-drawn 28-pixel experiment; rejected in favour of v6 |
| move-coins-v1 | Actual-game captures of coloured bevelled/embossed coin treatment |

Each generated study preserves source PNGs and prompts. Individual study previews and captures record experiments, not final release approval; old statements about a study being the current default are historical.
