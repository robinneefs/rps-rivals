# Hand move icons — first generated study

Requested 29 October 2026 for the existing move circles in RPS Rivals. Generated with the built-in image generation tool. Review candidates; not yet approved replacement art.

Targets: closed fist (Rock), open palm (Paper), two-finger V (Scissors). Warm ivory/peach skin, limited shading and dark purple outlines. Cuffs use red, yellow and cyan respectively. Transparent hand-only sprites; the game draws the circles and readiness states.

Intended native hand footprint: approximately 32 × 32 pixels, within the current circle's 42-pixel interior diameter. High-resolution originals must be reviewed at native size before installation.
